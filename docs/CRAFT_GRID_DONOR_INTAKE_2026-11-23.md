# Formula — GridCraft/Craft formats donor intake (2026-11-23)

**Status:** STUDY-ONLY candidate, not mathematical-core upgrade or new solver gate. Private cross-project cohort: `TTG-ecosystem/docs/DONOR_COHORT_STORYTOLD_VORK_2026-11-23.md`.

[GridCraft](https://github.com/storytold/gridcraft) and [craft-libs](https://github.com/storytold/craft-libs) may accelerate **spreadsheet file formats, formula UI/workbook inspection, data interchange and operator review**. These are not interchangeable with Formula's native mathematical constitution, discovery, compiler, formal falsification/certification, generation promotion or repeat-use proof. Keep Formula's existing P0–P13 acceptance unchanged.

**Candidate seam:** import version-pinned XLSX/sample workbook → convert spreadsheet cells/references/functions into an explicit typed Formula request (or refuse unsupported functions) → Formula certified result → roundtrip output with exact workbook cell/reference and error semantics. External workbook evaluation cannot attest mathematical correctness by itself.

**Qualification:** fixed source/license pins, redacted golden workbooks, function compatibility matrix, circular/recalculation/error handling, rounding/precision and Unicode/date semantics, adversarial formula/file handling, reversible export, independent result comparison, and explicit fallback. No auto-execution of spreadsheet macros or donor agent commands.

**Disposition now:** research queue; Formula math engine and its proof gates are untouched. Any UI/workbook integration belongs to a separately accepted interface stage, not the core solver.
