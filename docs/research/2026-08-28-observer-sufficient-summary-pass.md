# Observer-Sufficient Summary and Information Compression Research Pass

Date: 2026-08-28
Status: research checkpoint
Repository name: temporary only; not product identity

## Why this pass exists

Several previously separate research lines have converged on the same question:

- DP summary synthesis;
- contextual/Myhill-Nerode quotienting;
- coalgebraic behavioral minimization;
- open-system blackboxing;
- theory interface extraction;
- abstraction;
- statistical sufficient statistics.

The shared question is:

> **What is the smallest mathematical summary that preserves all information relevant to a declared future observer/query/decision family?**

Statistics provides a mature exact theory for one important version of this problem.

## 1. Sufficient statistics

For a statistical model depending on parameter `θ`, a statistic `T(X)` is sufficient when conditioning on `T(X)` removes any remaining dependence of the raw data `X` on `θ`.

Equivalently in common dominated models, Fisher-Neyman factorization expresses:

```
f(x; θ) = g(T(x), θ) h(x)
```

so all `θ`-relevant information passes through `T(x)`.

Sources:
- https://math.bme.hu/~marib/bsm/sufficient.pdf
- https://www.statslab.cam.ac.uk/~rjs57/MinimalSufficiency.pdf

This is mathematically the same kind of operation we want from a problem summary:

```
large object x
      ↓
summary T(x)
      ↓
all downstream target-relevant reasoning
```

where information irrelevant to the declared observer can be discarded.

## 2. Minimal sufficiency as a quotient

A standard criterion characterizes minimal sufficient statistics using an equivalence relation:

```
x ~ y
iff
f(x;θ) / f(y;θ)
    is independent of θ
```

under the theorem's regularity conditions.

Then the minimal sufficient statistic effectively identifies exactly those observations that carry the same information about `θ`.

Source:
- https://www.statslab.cam.ac.uk/~rjs57/MinimalSufficiency.pdf

This is strikingly parallel to Myhill-Nerode:

```
strings x,y equivalent
iff
no future suffix distinguishes language membership
```

and to behavioral blackboxing:

```
states x,y equivalent
iff
no admissible future observation distinguishes behavior
```

The underlying concept is **observer-relative equivalence**.

## 3. Minimal sufficient = coarsest lossless compression for observer

If `T` is minimal sufficient, every other sufficient statistic must refine/contain at least as much observer-relevant information (formally, `T` is a function of any other sufficient statistic under the relevant conditions).

This gives a model for `minimal summary` that is not based on byte size:

> a summary is minimal when any further quotient would destroy information required by the declared observer family.

That is precisely the property a synthesized DP state or black-box interface should aim for.

## 4. Blackwell comparison of information structures

Blackwell's comparison of statistical experiments orders information structures by downstream decision usefulness.

An experiment/information source `X` is sufficient/more informative than `Y` if `Y` can be generated by a stochastic transformation/garbling of `X`; equivalently under the theorem's setting, `X` yields at least as high a value for every decision problem in the class.

Sources:
- https://doi.org/10.1016/j.econlet.2024.112146
- https://www.mdpi.com/1099-4300/14/11/2254

Conceptually:

```
Information A >= Information B
```

when B can be derived from A but not necessarily conversely.

This is an **information order**, not a scalar entropy score.

That is very relevant to the project's certified-progress and representation-selection architecture.

## 5. Observer families matter

There is no universally minimal summary independent of what future questions must be answered.

Examples:

```
raw graph
  observer: connectivity
      -> connected-component quotient may suffice

raw graph
  observer: exact shortest paths
      -> much richer summary needed

sample data
  observer: parameter θ
      -> sufficient statistic Tθ

component state
  observer: boundary input/output behavior
      -> black-box relation
```

Therefore every summary/compression primitive must bind to an **observer contract**.

## 6. Observer contract hypothesis

Potential core object:

```
Observer {
    admissible_queries,
    admissible_contexts,
    required_result_semantics,
    reconstruction_requirements,
    error/exactness_class
}
```

A summary `S` is sufficient when the project can certify:

```
for every q in Observer:
    q(full_object)
      =
    q_from_summary(S(full_object))
```

or the appropriate probabilistic/approximate relation.

## 8. Markov categories and compositional sufficiency

Markov-category research develops sufficient statistics, conditioning, conditional independence, and related probability concepts categorically, covering discrete, measure-theoretic, Gaussian, and stochastic-process settings.

Source:
- https://www.sciencedirect.com/science/article/pii/S0001870820302656

This is especially interesting because it treats sufficiency in a **compositional** semantic framework rather than as isolated statistical formulas.

It strengthens the hypothesis that sufficiency can coexist with the project's open-system/categorical composition layer.

## 9. Information order versus representation cost

A summary can be more informative but more expensive.

The runtime should distinguish:

```
information/precision order
```

from:

```
storage cost
query cost
update cost
proof cost
```

Example:

```
full polyhedron
    more informative than
interval box
```

but the interval may be vastly cheaper and sufficient for a given sign query.

So representation choice can optimize cost subject to observer sufficiency.

## 10. Exact, probabilistic, and approximate sufficiency

The project should distinguish:

### Exact sufficient summary

All observer results are preserved exactly.

### Statistical sufficiency

Conditional distribution/information about declared parameter is preserved.

### Sound abstraction

Summary may include extra possible states but preserves proof direction for selected properties.

### Approximate sufficient summary

Observer outputs are preserved within a certified error/distance bound.

These must not share one `sufficient=true` bit.

## 11. Summary synthesis as discovery

The system may not know the sufficient statistic/state in advance.

It can search:

```
candidate summary S
       ↓
try to distinguish two full states merged by S
       ↓
counterexample context/query found?
       ├─ yes -> refine S
       └─ no  -> prove sufficiency / minimality in class
```

This is the same CEGIS/active-learning loop already found in contextual quotient and automata learning.

So `SUFFICIENT_SUMMARY` can be an active mathematical discovery problem.

## 12. Minimality classes

Absolute global minimality may be uncomputable/hard, consistent with the fundamental-limits checkpoint.

Therefore claims should be scoped:

```
MINIMAL_SUFFICIENT under theorem family T
MINIMAL_STATE among deterministic finite automata
MINIMAL_DIMENSION among linear weighted realizations
MINIMAL_SUMMARY within grammar G
PARETO_OPTIMAL(summary_size, query_cost, update_cost)
BEST_KNOWN
```

No universal shortest-summary oracle is assumed.

## 13. Primitive promotion consequence

A sufficient summary may itself become a new primitive.

Suppose a recurring family repeatedly collapses to state:

```
S(x) = (a,b,c)
```

and composition/update/query laws are certified.

Then `S` plus its laws can become the permanent interface/representation used by future problem solving, with the full original structure reconstructed only where needed.

This is another mechanism by which discovered mathematics becomes an executable instruction.

## 14. Search-economy consequence

When choosing between representations, the scheduler can ask:

```
Does representation R preserve every current observer obligation?
```

If yes, richer representations may be unnecessary.

This is stronger than generic information gain:

> once a cheaper representation is certified sufficient for all remaining obligations, extra information has zero mathematical value to the current campaign.

That can stop work early.

## 15. Core law

> **Retain exactly the mathematical information required by the declared future observer family; quotient or discard everything proved irrelevant to those observations.**

This may be one of the project's central compression principles.
